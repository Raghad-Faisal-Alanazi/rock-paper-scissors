# 🪨📄✂️ Rock Paper Scissors Game

A simple, fun implementation of the classic Rock Paper Scissors game — 
you go head-to-head against the computer!

## 🎮 How to Play
- Choose Rock, Paper, or Scissors
- The computer randomly picks its move
- The game compares both choices and declares a winner based on the classic rules:
  - 🪨 Rock beats ✂️ Scissors
  - ✂️ Scissors beats 📄 Paper
  - 📄 Paper beats 🪨 Rock

## ✨ Features
- Simple and interactive gameplay
- Random computer move generation
- Instant win/lose/tie results

## 🛠️ Built With
- Python
